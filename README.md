# StreamVibe Android APK downloads

This repository holds Android installer files for StreamVibe. It is separate from the Media God production code repository.

## Recovery builds, 22 October 2026

Version 1.1.0, versionCode 2, with the permanent published StreamVibe URL instead of the expired Base44 preview URL.

**Important:** These APKs are website-launch recovery builds. The separate Real-Debrid episode discovery fix has passed development tests but has **not yet been deployed to the public Next.js backend**. Real-Debrid episode playback cannot be considered fixed by these APKs alone. APKs are signed with a testing key and may require removal of an older differently signed APK before installation. Existing local data should be backed up before removing old installs.
